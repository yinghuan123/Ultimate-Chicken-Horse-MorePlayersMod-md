# Ultimate-Chicken-Horse-MorePlayersMod-md
超级鸡马 Ultimate Chicken Horse  8人游玩mod （基于MorePlayersMod优化）
Ultimate Chicken Horse MorePlayersMod 8人插件完整分享包

安装方法：
1. 关闭游戏。
2. 打开 Steam 游戏目录：Ultimate Chicken Horse 的游戏根目录，也就是有 UltimateChickenHorse.exe 的那个文件夹。
3. 把本压缩包里的所有文件和文件夹解压/复制到游戏根目录。
4. 如果提示合并 BepInEx 文件夹，选择合并；如果提示覆盖同名文件，选择覆盖。
5. 启动游戏。

当前配置：
- BepInEx 5.4.23.2
- EvenMorePlayers / MorePlayersMod v10.0.1
- newPlayerLimit = 8

注意：
联机时最好所有参与者使用同一个分享包，避免房间人数、插件版本或配置不一致。

卸载方法：
删除游戏根目录里的 winhttp.dll、doorstop_config.ini、.doorstop_version，以及 BepInEx 文件夹中对应的 MorePlayersMod 插件。
